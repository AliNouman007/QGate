# QA Memory V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a durable two-stage QA learning layer where automated/human findings become reviewable candidates, only human-confirmed findings become trusted memory, and active confirmed memories can be deterministically recalled into future Scenario Intelligence planning.

**Architecture:** Add a focused `qgate-qa-memory` package around immutable/auditable JSON-backed contracts, conservative candidate extraction from Browser Execution, explicit human review lifecycle, deterministic dedupe/recall, and a small Scenario Intelligence regression-hint adapter. Reuse Suitest Defect identifiers as occurrence links instead of duplicating defect management. Expose local authenticated API + `/qa-memory` dashboard while keeping Final Gate out of scope.

**Tech Stack:** Python 3.12, Pydantic v2, existing QGate Project/Impact/Scenario/Browser Execution packages, FastAPI, React 19/Vite/TanStack Query/TanStack Router, pytest, Vitest, Ruff, mypy.

**Spec:** `docs/superpowers/specs/2026-08-29-qa-memory-v1-design.md`

## Global Constraints

- Automated findings are candidates only; no automatic trusted-memory promotion.
- Human confirmation is mandatory before trusted recall.
- Rejected candidates never participate in trusted recall.
- Suitest `Defect` remains the occurrence/issue object; QA Memory stores reusable learning and only references defect ids.
- V1 memory is project-scoped; no cross-project/global learning.
- Recall is deterministic-first, bounded, inspectable and evidence-backed.
- AI, if added, is optional enrichment only and cannot change trust lifecycle or invent history.
- Historical memory lifecycle is supersede/deactivate, not silent deletion.
- Target repositories remain read-only; persistence lives in QGate-owned storage.
- Final PASS/BLOCK/MANUAL REVIEW REQUIRED is out of scope.
